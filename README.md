# Video Detection System

Система анализа видеопотока в реальном времени с детекцией объектов на базе **RF-DETR**, гибкой настройкой зон интереса (ROI) и поддержкой множества камер. Разработана для задач безопасности, ритейла, логистики и промышленного мониторинга.

---

## Возможности

### Детекция объектов

- **Модель**: RF-DETR Base (Real-Time Detection Transformer)
- **Классы**: 80 категорий COCO (person, car, bicycle, truck и др.)
- **Точность**: настраиваемый confidence threshold
- **Производительность**: пропуск кадров для оптимизации нагрузки (`FRAME_STEP`)

### Эффективность в сложных условиях

| Условие                       | Precision | Recall | F1-Score | Mean IoU | Mean Dice |
| :---------------------------- | :-------: | :----: | :------: | :------: | --------: |
| Густой туман                  |  0.9797   | 0.8801 |  0.9273  |  0.8935  |    0.9424 |
| Сильный дождь                 |  0.9272   | 0.9243 |  0.9258  |  0.8278  |    0.9029 |
| Сильный снег\метель           |  0.8954   | 0.8287 |  0.8608  |  0.8710  |    0.9284 |
| Люди в светоотражающей одежде |  0.9949   | 0.8580 |  0.9214  |  0.9177  |    0.9555 |
| Инфракрасные камеры           |  0.9955   | 0.4214 |  0.5921  |  0.9047  |    0.9488 |

### Работа с камерами

- **Мультикамерность**: переключение между источниками через UI
- **Динамическое добавление**: кнопка `+` для подключения новых камер без перезапуска
- **Поддерживаемые источники**:
  - `rtsp://` / `rtsps://` — IP-камеры
  - `http://` — веб-потоки
  - Путь к файлу — `.mp4`, `.avi`, `.mkv`

### Интерфейс и разметка

- **Зоны интереса (ROI)**: рисование полигонов мышью (ЛКМ — точка, ПКМ — замкнуть)
- **Фильтрация по классам**: выбор детектируемых объектов через выпадающее меню
- **Визуализация**: bounding boxes, лейблы с уверенностью, полупрозрачные зоны
- **Горячие клавиши**:

| Действие | Клавиша |             Описание |
| :------- | :-----: | -------------------: |
| Выход    |   `Q`   |  Завершить программу |
| Пауза    |   `P`   | Остановить обработку |
| Сброс    |   `R`   |     Удалить все зоны |

### Хранение данных

- **Локальное сохранение**: кадры с детекциями пишутся в `SAVE_DIR`
- **База данных**: запись метаданных (камера, класс, уверенность, путь к файлу)
- **Персистентность настроек**: зоны и выбранные классы сохраняются для каждой камеры отдельно в `camera_settings.json`

### Архитектура

- **Многопоточность**: отдельные потоки для сохранения кадров и записи в БД
- **Очереди**: `queue.Queue` для безопасной передачи данных между потоками
- **Модульность**: разделение на компоненты (`detection/`, `ui/`, `workers/`, `video/`)

## Быстрый старт

### 1. Установка зависимостей

````
```bash
git clone https://github.com/Pozdnyakov-Artem/proj
cd proj
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
````
### 2. Конфигурация камер: два режима работы
#### Режим 1: Статическая конфигурация (через .env)
##### 1. Настройте .env:
```
# Камеры (добавляйте по необходимости)
PATH_CAM_1=rtsp://admin:pass@192.168.1.10/stream
PATH_CAM_2=rtsp://user:pwd@192.168.1.11/ch1
PATH_CAM_3=./recordings/warehouse.mp4

# Параметры по умолчанию
DEFAULT_CAM_ID=1
DETECTION_THRESHOLD=0.5
VIDEO_SCALE=0.5
```
##### 2. Обновите config.py
Раскомментируйте 15 строку и добавть необходимое количество камер
##### Преимущества:
Камеры доступны сразу при старте
Настройки воспроизводятся на любом сервере
Легко версионировать через Git (кроме .env)
#### Режим 2: Динамическая конфигурация (через UI)
Идеально для разработки, тестирования или когда источники меняются часто.
##### 1. Запустите приложение
##### 2. Добавьте камеру:
* Нажмите + ADD CAMERA → введите URL в диалоговом окне → OK
* Камера мгновенно появится в списке и начнёт транслироваться
### 3. Настройка окружения

Создайте файл .env в корне проекта:

```
# Пути
SAVE_DIR=./frames
# === PostgreSQL ===
POSTGRES_USER=rfuser
POSTGRES_PASSWORD=rfpass
POSTGRES_DB=rfdetr_db
DATABASE_URL=postgresql+psycopg2://rfuser:rfpass@localhost:5433/rfdetr_db

# Камеры по умолчанию
DEFAULT_CAM_ID=1
PATH_CAM_1=rtsp://admin:pass@192.168.1.10/stream
PATH_CAM_2=video_test.mp4

# Параметры детекции
DETECTION_THRESHOLD=0.5
VIDEO_SCALE=0.5
DEFAULT_CLASS_IDS=[1]
```

### 3. Запуск одной командой
#### Windows(`run.bat`)
#### Linux/Mac (`run.sh`)
#### Запуск:
```
# Windows (PowerShell):
.\run.bat

# Linux/Mac:
chmod +x run.sh && ./run.sh
```

## Использование

### Переключение камер

1. Нажмите на кнопку Cam X в правом верхнем углу
2. Выберите камеру из выпадающего списка

### Добавление новой камеры

1. Нажмите на зелёную кнопку + рядом с переключателем камер
2. Введите URL потока или путь к файлу
3. Новая камера появится в списке и будет готова к использованию

### Разметка зон интереса

1. ЛКМ — добавить вершину полигона
2. ПКМ — замкнуть полигон и сохранить зону
3. Клавиша R — очистить все зоны текущей камеры

### Выбор классов детекции

1. Нажмите на кнопку Classes в левом верхнем углу
2. Отметьте нужные классы чекбоксами
3. Повторный клик по кнопке или клик вне панели закроет меню

### Управление воспроизведением

| Действие            | Клавиша   |
| :------------------ | :-------- |
| Пауза / продолжение | P         |
| Выход из программы  | Q или ESC |
| Сброс зон           | R         |
